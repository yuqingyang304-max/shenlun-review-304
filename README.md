# 申论批改304

对照用户提供的申论模板批改手写答卷，交付小题红线版及无新增红线版 PDF。使用时附上参考模板和按题序排列的答卷照片。

- 支持读取 GitHub 文件的软件可以直接读取本仓库的 [SKILL.md](SKILL.md)，然后按其规则批改附件。
- 支持导入 Agent Skills 或 Codex 插件的软件，可以[下载完整插件包](shenlun-review-304.zip)并解压。技能文件夹为 `skills/shenlun-review-304`，完整插件根目录包含 `.codex-plugin/plugin.json`。
- 访问私有仓库需要 GitHub 读取权限。批改软件需要能够处理附件、图片和 PDF。
